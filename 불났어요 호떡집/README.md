# 🔥 불났어요 호떡집 (Namdaemun Hotteok Tycoon)

남대문 시장의 365일 문전성시 맛집! 고객만족 100% 호떡집의 주인이 되어 100단계 호떡 마스터에 도전하는 타이쿤 게임입니다.

---

## 🎮 게임 실행 방법
- 별도의 서버 설치나 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 모던 웹 브라우저에서 바로 플레이할 수 있습니다.

---

## 📜 게임 규칙 및 요구사항 구현 명세

### 1. 단계 및 시간 시스템
- **총 100단계**: 1단계부터 100단계까지 순차적으로 도전 가능합니다.
- **플레이 시간**: 각 단계별 플레이 시간은 **1분 30초(90초)**로 고정되어 있습니다.
- **동글동글 귀여운 손님 캐릭터**:
  - 노란색 이모지가 아닌 자연스러운 **스킨 톤**과 귀엽고 둥글둥글한 캐주얼 만화풍 일러스트 캐릭터 5종이 손님으로 방문합니다.
- **1~5개 다중/다종 주문 시스템**:
  - 각 손님은 **1개부터 최대 5개까지** 호떡을 주문합니다.
  - 동일한 호떡을 여러 개 주문할 수도 있고(예: 꿀호떡 3개), 여러 종류를 섞어서 주문할 수도 있습니다(예: 꿀호떡 2개 + 야채호떡 1개 + 씨앗호떡 1개).
- **손님 대기 시간 및 페널티**:
  - 손님 한 명당 기다리는 시간은 **1분(60초)**이며, 시간이 지나 손님이 떠나면 **-10점** 감점됩니다.
- **손님의 실시간 감탄 멘트(리액션 말풍선)**:
  - 손님이 원하는 호떡을 완성하여 전달하면 캐릭터 머리 위에 **'맛있다!', '음~', '또 사먹자!', '역시 맛집이야!', '완전 꿀맛!', '겉바속촉 최고!'** 등의 생생한 감탄 말풍선이 랜덤으로 뜹니다.
- **단계 통과 조건**: 해당 단계의 주문 호떡을 **80% 이상** 수행하면 다음 단계로 넘어가며, 80% 미만이면 게임 오버됩니다.

### 2. 호떡 레시피 및 합성 규칙
재료 버튼을 누르면 반죽 조합대에 들어가며, 레시피에 맞춰 **[호떡 굽기]**를 누르면 노릇노릇 구워집니다.

| 호떡 종류 | 필요 재료 | 기본 점수 |
| :--- | :--- | :--- |
| **꿀호떡** | 밀가루, 물, 기름, 설탕 | 100점 |
| **야채호떡** | 밀가루, 물, 기름, 당면, 야채 | 120점 |
| **씨앗호떡** | 밀가루, 물, 기름, 설탕, 시나몬가루, 견과류 | 150점 |
| **매콤호떡** | 밀가루, 물, 기름, 당면, 야채, 고춧가루 | 140점 |
| **팥호떡** | 밀가루, 물, 기름, 설탕, 팥 | 130점 |

### 3. 직관적인 레시피 확인 팝업
- 손님이 주문한 호떡 말풍선이나 손님 카드를 클릭하면 **해당 호떡에 필요한 재료 목록 창**이 즉시 나타납니다.
- 레시피 창에서 `[이 재료 바로 담기]`를 누르면 원클릭으로 필요한 재료를 반죽대에 자동 배치할 수 있습니다.

### 4. 무작위 '?' 행운의 랜덤 재료
- 일정 확률로 번쩍이는 **'?' 황금 랜덤 재료**가 등장합니다.
- '?' 재료를 다른 호떡 재료와 함께 합성하여 호떡을 만들면 **1~100점의 무작위 추가 보너스 점수**를 획득합니다.

### 5. 캐릭터 및 엔딩 연출 (고화질 일러스트 포함)
- **중년 부부 사장님 캐릭터** 일러스트가 상황별로 연출됩니다.
  1. **다음 단계 진출 시**:
     - 멘트: `"좋았어! 더 열심히 하자!"`
     - 일러스트: 엄지를 치켜세우며 활짝 웃는 중년 부부 사장님 (`owner_smiling.jpg`)
  2. **게임 오버 시**:
     - 멘트: `"고객 만족 100%의 길은 어려워"`
     - 일러스트: 눈물을 흘리며 아쉬워하는 중년 부부 사장님 (`owner_crying.jpg`)
  3. **100단계 최종 클리어 시**:
     - 멘트:
       > "사람들이 많이 찾는 남대문!  
       > 그 중에서도 365일 장사가 사람들이 많은 그 곳  
       > '불났어요 호떡집'  
       > 고객만족 100%를 경험하고 싶다면  
       > 불났어요 호떡집으로 오세요~"
     - 일러스트: 남대문 시장의 수많은 손님들이 호떡을 먹으며 활짝 웃고 있고, 사장님 부부가 열심히 호떡을 만드는 감동의 그랜드 피날레 일러스트 (`ending_celebration.jpg`)

### 6. 테스트 및 편의 기능 (단계 이동)
- 상단 **STAGE 배지** 또는 **단계이동(⚙️)** 버튼을 누르면 1~100단계 중 원하는 단계로 즉시 점프하거나, 즉시 스테이지 클리어 테스트를 진행할 수 있습니다.
- Web Audio API 기반의 지글지글 굽는 소리, 성공 효과음, 페널티 경고음, 신나는 펜타토닉 시장 배경음악이 기본 탑재되어 있습니다.
