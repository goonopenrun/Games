## 🕹️ 등록된 게임 목록

### 1. 🧺 [모아모아 과일가게](./모아모아%20과일가게/README.md)
* **장르**: 7×7 매치-3 퍼즐 & 상점 확장 시뮬레이션 게임
* **설명**: 같은 과일을 3개 이상 맞춰 점수를 얻고, 100단계까지 스테이지를 클리어하며 작은 과일 노점에서 최고급 과일 백화점까지 가게를 확장해 보세요!
* **주요 특징**:
  - 5개 이상 매치 시 특수 물폭탄 아이템 생성 (주변 5개 과일 폭발)
  - 한 줄 매치 시 장바구니 보너스 스테이지 진입 (30초 동안 추가 점수 획득)
  - 스테이지별 방해 요소 (얼음 과일, 썩은 과일)
  - 단계별 성장 일러스트 (10단계, 30단계, 60단계, 100단계)
* **바로 플레이**: [모아모아 과일가게 게임 폴더](./모아모아%20과일가게/)

### 2. 🐱 [따뜻한 집을 찾아서 : 아기 고양이의 모험](./아기%20고양이의%20모험/README.md)
* **장르**: 2D 어드벤처 미로 탐험 & 미니게임
* **설명**: 눈보라 치는 추운 겨울, 버려진 아기 고양이가 따뜻한 보금자리를 찾아 떠나는 100단계의 힐링 여정입니다.
* **주요 특징**:
  - 100가지의 다양한 미로 맵과 장애물
  - 따뜻한 털실, 물고기 간식 수집 및 늑대 회피
  - 미니게임 및 엔딩 스토리
* **바로 플레이**: [아기 고양이의 모험 게임 폴더](./아기%20고양이의%20모험/)
