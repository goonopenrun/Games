# 🐱 따뜻한 집을 찾아서 : 아기 고양이의 모험
> **A Lost Cat's Warm Journey** - 눈길 속을 헤매는 아기 고양이가 따뜻한 보금자리를 찾아 떠나는 힐링 어드벤처 미로 게임

---

## 🎮 게임 소개
눈보라 치는 겨울, 길을 잃은 아기 고양이가 되어 따뜻한 모닥불과 집을 찾아 모험을 떠납니다.  
미로 속에서 따뜻한 캔 참치와 생선을 모으고, 눈사람과 추위를 피해 안전한 집으로 인도해 주세요!

- **100개의 다양한 스테이지**: 난이도별로 생성되는 다채로운 미로 스테이지
- **미니게임 및 보너스**: 캔 참치와 생선 모으기, 스릴 넘치는 미니게임
- **감성적인 사운드 & 비주얼**: 부드러운 눈 내리는 애니메이션과 웹 오디오 신디사이저 효과음
- **모바일/PC 지원**: 키보드 방향키 및 터치 가상 패드(D-Pad) 완벽 지원

---

## 🕹️ 조작 방법
- **이동**: `방향키 (↑, ↓, ←, →)` 또는 `W, A, S, D`
- **모바일**: 화면 하단의 가상 조이패드 터치
- **일시정지/재개**: `ESC` 또는 화면 상단 일시정지 버튼

## 📁 프로젝트 구조
```
아기 고양이의 모험/
├── index.html        # 메인 웹 페이지 및 캔버스 뷰
├── style.css         # 감성적인 다크/스노우 테마 글래스모피즘 스타일
├── js/
│   ├── main.js       # 앱 진입점 및 이벤트 리스너
│   ├── game.js       # 게임 루프 및 코어 엔진
│   ├── maze.js       # 미로 자동 생성 알고리즘
│   ├── sprites.js    # 아기 고양이 및 아이템 스프라이트 렌더러
│   ├── audio.js      # Web Audio API 기반 효과음/BGM
│   └── minigame.js   # 미니게임 로직
└── README.md         # 게임 안내서
```
